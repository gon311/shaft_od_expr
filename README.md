# 샤프트 외경(OD) 측정 — 이다겸 실험 저장소

> 이 저장소는 팀 파이널 프로젝트(백라이트 사진으로 샤프트 외경 Ø20.02 ±0.01mm를 재는 과제)의
> **일부**입니다. 팀 전체 코드가 아니라 **이다겸 개인이 수행한 실험만** 모아 둔 저장소이며,
> 팀원(선행 개발자·팀장)의 측정 엔진·분석 코드는 여기 포함되어 있지 않습니다(각 실험 문서에서
> "팀원A"·"팀원B"로 비교 대상으로만 언급됩니다).

## 과제 배경

백라이트로 찍은 샤프트 실루엣 사진에서 위·아래 경계를 찾아 지름을 재고, 공차
±0.01mm(≈0.27px, 1px ≈ 0.037mm) 안에서 양품/불량을 가려내는 것이 목표입니다.

## 지금까지의 결론 (2026-11-06 기준)

**2차(10/8, 130장)와 3차(10/21, 150장) 데이터 모두에서, 미리 정한 주 방법은 평균 찍기(정상
시편 평균값을 그대로 답하는 방식)를 사전 기준만큼 이기지 못했습니다.** 원인은 측정 방법보다
사진마다 달라지는 촬영 조건(배율 드리프트, 장착 변동, 초점)이 찾으려는 시편 간 차이(정상
시편 범위 약 21µm)보다 크다는 데 있다고 봅니다. 다만 정상 시편이 9개뿐이라 대부분의 결론은
"효과 없음"이 아니라 "이 자료로는 구분할 수 없음"입니다.

| 단계 | 결론 |
| --- | --- |
| 1st (YOLO 모델 비교) | 6개 모델 비교 결과·캘리브레이션 수치는 `results/` CSV·JSON 참고 |
| E1–E6 (측정·보정, 10/8) | 보정식 확정 불가. 경계 정의는 cross50/moment 후보로 좁힘 |
| E2 (증강) | 안전한 변형은 일부뿐(어둡게·대비 축소·소폭 평행이동) |
| E7 (엣지 학습 프로토타입) | teacher(cross50) 복제까지는 성공, GT 없어 정확도는 미확인 |
| E10 (실측 지름 파인튜닝, 10/8) | 8개 변형 전부 평균 찍기(MAE 5.78µm)를 이기지 못함 → "셋업 잡음 흡수"로 판단 |
| E6·E10 재실행 (10/21) | 주 방법(V1 물리 스케일) 8.48µm로 평균 찍기 6.64µm보다 나쁨. 핀 비율 선형(3.99µm)이 가장 좋았지만 사전 기준 미달. NG 방향은 맞음. 본시험 중 배율 −0.19% 드리프트 |
| E11 (표면거칠기) | 시편 고유 굴곡과 Rz의 관계는 판단 불가. 라벨 잡음만으로 판정이 막힐 가능성은 배제 못함 |
| E12 (끝열 스파이크) | 사진 좌표 고정 결함보다 역광판 질감을 따라가는 현상. 원인 부위는 10/21 자료로 가릴 수 없음 |
| E13 (거칠기 분석 재현) | 선행개발자 분석의 양의 상관은 재현되지 않음(r +0.13). E11 결론 유지 |
| E14 (중앙 구간 대표값) | 측정 구간을 중앙 10·5개소 상당으로 좁혀도 실측 오차가 줄지 않음(주 비교 2개 모두 구분 불가) |

자세한 수치와 근거는 [`experiments/2nd/README.md`](experiments/2nd/README.md)와

## 실험 중단

2026-11-11 프로젝트 최종발표에 맞춰 **이 저장소의 실험은 E14를 끝으로 중단합니다.**
추가 촬영이 어려워 E12 이후는 10/21 자료만으로 분석했고, 남은 질문(배율 드리프트·장착 변동을
줄이면 시편 간 차이가 보이는가, 끝열 스파이크의 원인 부위)은 새 촬영 없이는 답하기 어려워
열린 채로 남깁니다. 후속 작업을 한다면 참고할 촬영·분석 제안은 E11·E13 보고서의 "다음 제안"
절에 있습니다.

## 환경

Python 3.11, requirements는 각 실험 폴더(`experiments/2nd/requirements.txt`) 기준입니다.
E11 이후 일부 단계는 macOS 기본 Python 3.9에서 돌렸고, 정확한 버전은 각 실험 README에 있습니다.
